# PC海阔世界规则导入指引

适用：本项目PC客户端。来源为deepcloud-ui/src/components/hiker/clipboard-detector/HikerUnifiedImportModal.tsx的界面实现；这里核对的是源码文案，不能声称已操作窗口。Android须另行核对及实机验证。

用户打开统一导入窗口后：

- 口令或链接：选择“口令 / 直链导入”，粘贴真实口令或链接，点击“解析并导入”。“粘贴剪贴板”仅为窗口内按钮，不等于自动弹窗承诺。
- JSON文件：选择“文件 / 备份恢复”，点击“选择备份包或规则文件”，选中已交付的JSON。

不知道打开窗口的入口时不要编造右上角菜单、底部“我的”或手机“规则管理”路径；可只给窗口内已核对步骤，并说明未操作GUI。不要把手机端IJK/ExoPlayer等选项写成PC排障菜单。

仅交付实际文件链接或文件名及少量步骤。长口令必须由实际导出文件原样取用；不在自然语言答复里重新猜写或拼接大段Base64。离线长口令不等于已发布云剪切板短口令。
