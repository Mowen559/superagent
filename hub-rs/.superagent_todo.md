## Gateway 架构审查与修复建议
- [ ] **问题 1：包结构不符合 DDD 规范**。`AGENTS.md` 规定每个微服务必须包含 `api`, `application`, `domain`, `infrastructure`, `config` 分层。当前 `gateway` 包含 `controller`, `manager`, `filter`, `exception` 等非标准包。
- [ ] **修复建议 1**：将 `controller` 包重命名为 `api`。
- [ ] **修复建议 2**：将 `filter` 和 `exception` 移动到 `infrastructure/web` 或 `api/filter` 下。
- [ ] **修复建议 3**：将 `manager`（如 `AppSecretManager`）移动到 `infrastructure/security` 或 `domain/service` 中，具体取决于其是否包含核心业务逻辑。
- [ ] **修复建议 4**：补充缺失的 `application` 和 `domain` 层目录（即使暂时为空，也应保持结构一致性）。
