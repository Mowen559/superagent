## Why

用户从前端要求分析本地安装应用并转成海阔规则时无法完成。已确认 Skill Scout 与 skill_tool 的发现目录不一致，重复同名技能占用挂载名额，规则工具链被硬编码为相对路径，YAML 多行描述被解析成 `>`。之前的原生能力夹具不能证明这条业务链路成功。

## What Changes

- 统一技能发现目录、确定性优先级和按名称去重，包含运行包中的技能。
- 自动挂载与 skill_tool 返回同一技能的真实绝对路径、资源目录和实际存在的脚本；支持多行描述。
- 区分应用可行性调查与规则交付，不以静态校验或 HTTP 200 冒充真实数据/播放成功。
- 通过不依赖桌面的回归及真实 worker 重放验证修复；对指定应用保留脱敏接口证据。

## Capabilities

### New Capabilities
- `skill-execution`: 可定位、可读取、可执行并可核验的领域技能。

## Impact

修改 Skill Scout、skill_tool 与 worker 的技能指引。保留现有工具参数与写入范围，不放宽文件访问边界，不运行桌面自动化，不覆盖用户已有规则，不自动发布或推送。
