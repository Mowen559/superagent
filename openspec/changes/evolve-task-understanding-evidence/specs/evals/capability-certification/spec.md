# Spec Delta

## ADDED Requirements

### Requirement: 有预算且可追溯的需求理解评测
系统 SHALL 默认离线预览合成规划夹具；真实模型评测必须显式启动，固定请求配置与轮次预算，并记录实际模型、夹具指纹、错误轨迹及输入输出用量。

#### Scenario: 离线预览
- **WHEN** 运行评测入口但未显式选择真实模型执行
- **THEN** 仅输出合成任务资料，不调用外部模型或上传真实仓库内容。

### Requirement: 评测结论不越过证据边界
系统 MUST 区分结构通过、词面覆盖和真实业务验收；单个规划样例不证明编码成功率，输出用量降低不代表总用量降低，本能力在缺少充分真实任务认证时保持 Experimental。

#### Scenario: 样例成功但没有真实业务执行
- **WHEN** 评测只完成合法规划和约束检查
- **THEN** 报告说明范围，不宣称全部 Golden Evals 已落地或自动晋级认证。
